# Executable Prompts

This directory contains three concrete video-generation prompts derived directly from catalog templates:

- `prompt_01_alignment_snap.yaml` — highest-priority product-present proof;
- `prompt_02_problem_floor_reveal.yaml` — delayed product reveal with a 2.0-second deadline;
- `prompt_03_macro_surface_push.yaml` — texture-first opportunity test.

Each prompt is limited to exactly 3 seconds and includes product inputs, timeline, camera behavior, negative constraints, and independent review anchors. The review anchors are not a claim that the prompt succeeded; they specify what must be checked in the rendered result.

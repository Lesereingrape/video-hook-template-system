# Evaluation

The final evaluation package includes:

- a reproducible scoring model for all ten templates;
- rankings for expected attention, SKU reusability, generation feasibility, and category fit;
- a review checklist with independent Keep, Revise, and Drop criteria;
- the three templates selected for first testing and the rationale.

The scoring model uses four ordinal 1–5 dimensions with explicit weights. The review checklist evaluates rendered evidence at fixed checkpoints and keeps generation logic separate from grading logic.
